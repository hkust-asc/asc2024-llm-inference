# Source

This repository is an ASC Team study fork. It is not an official ASC Committee repository, and it is not a university endorsement.

- Contest: ASC24 (2024). The upstream repository is named ASC24-LLM-inference-optimization and its README refers to the ASC24 Committees, but the README title and GitHub description still say ASC23. This fork keeps that wording unchanged.
- Upstream: https://github.com/ASC-Competition/ASC24-LLM-inference-optimization
- This fork: https://github.com/hkust-asc/asc2024-llm-inference

## What is in this fork

10k-sample dataset (`scrambled_sampled_dataset.json`) and baseline code for the LLM inference optimization challenge. Model weights are not included; upstream README points to LLaMA 2 70B on Hugging Face.
